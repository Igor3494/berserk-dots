# Установка по шагам

Инструкция для чистого или уже работающего Arch Linux. Каждый шаг можно проверить перед следующим.

## 0. Что нужно

- Arch Linux, работающий интернет (`ping -c 3 archlinux.org`);
- обычный пользователь с `sudo` (не root). Если пользователя ещё нет: `sudo ./setup-account.sh` из папки репозитория;
- около 3 ГБ свободного места.

## 1. Скачать

```bash
sudo pacman -S --needed git
git clone https://github.com/Igor3494/berserk-dots.git
cd berserk-dots
```

## 2. Посмотреть, что будет сделано

```bash
./install.sh --dry-run
```

Режим ничего не меняет: только печатает команды. Прочитай список пакетов в папке `packages/` и файлы в `config/`.

## 3. Запустить установку

```bash
./install.sh
```

Покажется меню:

```
 1) [x] base      Базовая система ...
 2) [ ] gpu       NVIDIA для гибридных ноутбуков ...
 3) [x] desktop   Рабочий стол: Hyprland + Noctalia ...
 ...
```

- цифры через пробел включают и выключают модули (например, `2 9`);
- `a` выбирает всё, `n` снимает всё, Enter запускает установку.

Модули `gpu` и `asus` включай, только если у тебя гибридная графика AMD + NVIDIA и ноутбук ASUS.
Потом установщик необязательно спросит имя компьютера и данные для git (Enter пропускает вопрос).

## 4. Запустить Hyprland

Если у тебя есть менеджер входа (sddm, greetd), выбери сессию Hyprland. Иначе из консоли:

```bash
Hyprland
```

При первом запуске Hyprland создаст свой конфиг. Если модуль `theme` или `dolphin` пропустил файл конфига,
запусти установщик ещё раз и выбери только эти модули.

## 5. Первые настройки

1. Noctalia откроет мастер первой настройки. Пройди его.
2. Положи свои обои в `~/Pictures` и выбери их: `SUPER + W`.
3. Знак для терминала: PNG на прозрачном фоне сохрани как `~/Pictures/berserk-logo.png` и открой новый терминал.
4. Видеообои (модуль `video`): ролик в `~/Videos`, затем
   ```bash
   noctalia msg plugins enable noctalia/mpvpaper
   noctalia msg panel-toggle noctalia/mpvpaper:picker
   ```
5. Нажми `SUPER + H`: откроется окно со всеми сочетаниями клавиш.

## 6. Проверка

```bash
hyprctl configerrors          # должно быть пусто
noctalia config validate      # без предупреждений
```

## 7. Обновление

```bash
cd ~/berserk-dots
git pull
./install.sh
```

Модули можно запускать повторно: свои изменения в `~/.config` установщик сначала сохраняет в `~/.config-backup-ДАТА/`.

## 8. Откат

Верни файл из копии, например Hyprland:

```bash
cp ~/.config-backup-ДАТА/.config/hypr/hyprland.lua ~/.config/hypr/hyprland.lua
hyprctl reload
```

Резервную копию всех своих настроек делает `./backup.sh` (файлы попадают в `~/backups`).

## Частые вопросы

**Сверху жёлтая или красная полоса.** Ошибка в конфиге Hyprland: смотри `hyprctl configerrors` и верни копию (шаг 8).

**Тема Noctalia не меняется.** Настройки, заданные мышкой в самой Noctalia, лежат в
`~/.local/state/noctalia/settings.toml` и перебивают файлы репозитория. Удали оттуда лишние блоки.

**Сочетание клавиш не срабатывает.** Возможно, оно занято стандартным. Установщик отключает конфликтующие
стандартные сочетания, но проверить можно так: `grep -n 'hl.bind' ~/.config/hypr/hyprland.lua`.

**Dolphin выглядит по-старому.** Перезайди в сессию (переменные окружения подхватываются только так).

**Нет знака в терминале.** Нет файла `~/Pictures/berserk-logo.png`. Без него `fastfetch` показывает текст без картинки.
