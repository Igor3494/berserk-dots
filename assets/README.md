# Обои, видео и логотип

Сюда ничего не кладётся: арты и видео по Berserk защищены авторским правом, поэтому в репозиторий не входят
(`.gitignore` их и не пропустит).

Что нужно сделать самому:

- **Обои-картинки:** скачай, например, с wallhaven.cc и положи в `~/Pictures`.
- **Видеообои:** положи ролик в `~/Videos` (лучше mp4 1080p, без звука) и выбери его командой
  `noctalia msg panel-toggle noctalia/mpvpaper:picker`.
- **Логотип для терминала:** PNG на прозрачном фоне сохрани как `~/Pictures/berserk-logo.png`.
  Без него `fastfetch` показывает системную информацию без картинки.
